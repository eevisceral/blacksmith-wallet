# Security

Blacksmith V1 is self-custodial. The wallet you connect is the only signer. This page never receives the key, and no operator can recover the account.

## Reporting vulnerabilities

Report security issues through GitHub Security Advisories on this repository. Do not open a public issue for sensitive reports.

**Never** send private keys, seed phrases, or wallet backups in a report. Describe impact and reproduction steps only.
